Accessibility Statement

This website is built to be usable by every visitor, including people using a screen reader, a keyboard on its own, or a screen magnified to 200 per cent. Sperbeck Chiropractic Corporation is responsible for it.

What is built in

These are properties of how the site is built, not a widget added on top.

  • Semantic landmarks, and one H1 on every page.
  • A lang attribute on the html element. The legacy site omitted it entirely, which is a conformance failure on an accessibility page in particular.
  • Real text rather than words baked into images, with meaningful alt text on every image. On the legacy site 24 alt attributes named a different city and several key images shipped empty alt.
  • Navigation reachable by keyboard, with a visible focus style and no dead parent links.
  • Text and background pairs contrast-tested at 4.5:1 as part of the token system. The inherited orange and grey were vendor presets and were never contrast-verified.
  • Tap targets large enough to hit on a phone.

Each of those is checkable against the pages themselves rather than taken on trust.

The standard we work to

This site is built to target WCAG 2.1 Level AA. That means we work to meet it and we review the site against it.

It does not mean every page is fully conformant, and we do not claim that.

Telling us about a barrier

If something on this site does not work for you, tell the office. There are two ways, and neither ranks above the other here.
